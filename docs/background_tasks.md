# 后台任务

后台 Shell 与 Agent 的生命周期、结果展示与自动唤醒。

## 1. 工具块展示

- Shell 与 Agent 的后台执行保留在原调用位置，按发起顺序阅读。
- 运行中的字形保持动作形状，以运行色脉冲；结果列显示"后台运行中"。
- 完成、失败、停止和中断在原位更新。Shell 展示退出码与实际输出，Agent 展示 Markdown 最终回复。
- 完成时不产生 Notice、独立消息、自动展开或滚动。
- TUI 工作段在所属后台任务运行期间保持展开，全部结束后恢复正常折叠。点击右侧栏的后台任务时，只在所属工作段已折叠时展开该段并定位到原工具块；工具块自身的展开状态不变。
- `TaskOutput` 归入原工具块，查询错误保留在块内；找不到原任务时保留独立工具行。
- `SendMessage` 开启新的会话交互，回复自动回投调用会话。`TaskStop` 保留独立的停止动作，原任务同步变为已停止。
- 状态更新保留用户的展开选择。运行状态与主助手是否生成分开计算。

## 2. Shell 实时输出

- **采集**：前台、后台 Shell 共用管道采集层，stdout / stderr 按读取顺序进入原调用的展示输出，无换行内容也会发布。每条管道独立处理分块 UTF-8 和 ANSI 状态；展示层去除控制序列，CR 进度行原位替换。
- **事件**：`ShellOutputUpdated` 按 `call_id` 更新 `SessionView.shell_outputs`，启动回执提交前即可显示。后台生命周期由 `BackgroundTaskUpdated` 表达；输出事件只更新展示，不产生模型输入，也不触发自动唤醒。
- **缓冲**：每条命令保留最多 256 KiB 的展示尾部，环形缓冲淘汰头部。读管道只修改缓冲并合并唤醒，会话约每 100ms 提取脏调用快照，运行中与空闲时都处理。正常退出时读尽管道后发布终态；停止与失败保留已采集的输出。
- **模型回执**：前台完整的 stdout / stderr 分别写入匿名临时文件，回执保留 stdout 加 `STDERR` 分节；大输出合并保存到 `tool_outputs` 目录，模型回执保留有界头部与文件路径。
- **持久化**：前台最终展示快照随 `ToolResult.shell_output` 保存，后台随 `BackgroundTask.shell_output` 保存；中间输出只驻留内存。重载后从结构化快照恢复展示，尚未结束的输出标为中断。回退移除调用后，后续输出不再加入投影。
- **Web**：收起的工具块不挂载正文。展开后输出区跟随末尾，向上阅读时暂停跟随，回到底部后恢复。
- **TUI**：预览展示最新的尾部行。输出变化只重排对应的工具块，保留其他历史行缓存与阅读位置。
- 管道执行的可见时机取决于子进程刷新输出的时机。

## 3. 领域与传输

- core 的 `BackgroundTask` 是强类型任务快照，含任务身份、状态、输出、退出码与截断信息。
- 状态文案由应用投影生成。TUI 终态的 5 秒计时保存在应用 `SessionView.background_finished`，不进入领域模型或 JSONL。
- 启动和查询的 `ToolResult` 携带快照；后台完成 reminder 所在的 `Turn` 携带最终快照。
- JSONL 追加记录最终结果，不重写历史工具结果。
- 模型接收 reminder 并按自动唤醒规则续跑。供应商协议不变，UI 不解析 reminder 正文。
- `BackgroundTaskUpdated` 驱动 `SessionView.background_tasks`；Web 首帧与 SSE 增量传递相同投影，TUI 使用同一状态源。
- 重载时按历史快照重建投影，状态为运行中的任务标为已中断，并保留已有输出。任务不跨进程恢复。
- Shell 任务 ID 全局唯一，重载或回退后复用的 ID 不会污染旧工具块。

## 4. 完成与持久化时序

1. 工具回执落盘，同时发布启动或查询快照。
2. 后台完成时立即发布结构化状态，reminder 排队投递。
3. 在工具结果已配对的安全轮隙追加 reminder 与最终快照，然后才调用模型。
4. 空闲完成路径先持久化结果再组装模型。取消或调用失败收尾时同样冲刷完成队列，保持"不自动续跑"。
5. 回退按保留的历史重建任务投影。正在运行的任务继续执行，完成时不向已删除的工具块添加状态。

## 5. 自动唤醒

- 启动后台 Shell、后台 Agent 或发送跨会话消息时，运行时登记异步工作。
- 模型没有可推进的工作时结束响应，会话保持空闲并监听事件；等待期间不调用模型，也不轮询。
- 任一结果到达，空闲会话自动续跑；忙时入队，在工具调用与回执配对后注入。同一轮隙内已到达的结果一起交给模型。
- 完成通知经会话命令队列投递；Shell 结果持久化后才确认消费。会话回复由独立回执捕获，后续轮次不会覆盖结果。
- CLI 输出通道与程序化投递回执保留到后台工作和续跑完成。子代理本轮结束时若还有后台工作，其最终报告在续跑结束后返回。
- 用户停止或模型调用失败后暂停自动续跑，后续结果继续更新工具块并持久化；新输入恢复调度。
- `TaskOutput` 用于按需查看进度或读取更多输出；模型无需调用工具等待完成。
- 后台工作只存在于进程内，不跨进程恢复。常驻命令由 `TaskStop` 或退出进程终止。

会话任务与后台资源的关闭边界见 [architecture §4](architecture.md#4-外部消费与生命周期)。
